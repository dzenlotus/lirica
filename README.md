# Лирика

Монохромный редактор стихов на русском языке: текст на основном экране, библиотека и настройки по запросу. React, TypeScript, Tiptap и локальный ChatMock с **GPT-6 Luna**.

## Запуск

Нужен Node.js 24 и запущенный, авторизованный ChatMock на `http://127.0.0.1:8000`.

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. Одной командой запускаются интерфейс и сервер подсказок. Настройки подключения по умолчанию уже работают с локальным ChatMock. Для изменения скопируйте `.env.example` в `.env`.

## Возможности

- Главная открывает новый пустой стих. Прежние стихи остаются в библиотеке, нетронутые пустые черновики не сохраняются.
- Автоматические ударения расставляются после паузы при наборе: однозначные формы берутся из локального словаря RUAccent, а ChatMock выбирает допустимое чтение омографов по контексту. Неизвестные слова остаются без догадки и доступны для ручного уточнения. Ручные отметки и ё имеют приоритет над автоматикой для всего слова. Автоматические отметки не меняют исходный текст редактора; при копировании и экспорте они добавляются к нему.
- Волнистое подчёркивание отмечает отклонения от размера. Нажмите на него: под текстом появится объяснение с конкретным словом, ударением и советом, как перестроить строку, сократить или дополнить её. Между отклонениями одной строки можно переключаться стрелками. Пунктир отмечает неоднозначное произношение, которое можно уточнить вручную. При смене размера проверка выполняется локально, без нового запроса к модели.
- «Предложить исправления» запрашивает до трёх полных замен выбранной строки. Варианты проверяются по словарным ударениям и размеру, сохраняют последнее слово и все ручные отметки. Ударные гласные выделены для сравнения. Автор оценивает смысл и нажимает «Применить»; заменяется только эта строка, Cmd/Ctrl + Z отменяет замену. Изменение текста, строки или настроек отменяет устаревшую подборку. Если строка однозначно подходит другому размеру, можно явно выбрать его для всего стиха.
- Ударения: выделите гласную или поставьте курсор сразу после неё и нажмите «Ударение» либо Cmd/Ctrl + Shift + U. Повторное действие снимает ударение. Ё уже под ударением. Знаки сохраняются в тексте и экспорте.
- В примерах размеров выделены ударные гласные и показана схема ритма.
- «Автоопределение» в поле размера показывает найденный размер, число стоп и фактическую рифмовку под стихом и в настройках. Размер проверяется по словесным ударениям; для каждой строки нужны хотя бы два надёжно ударных многосложных слова. Неполные строки не отменяют результаты предыдущих, неоднозначный или неоднородный ритм обозначается явно. При разном числе стоп показаны общий размер и число стоп выбранной строки. Буквы у строк отражают найденные группы рифм и начинаются заново после пустой строки. Для уверенной схемы нужны хотя бы четыре строки; рифмы определяются приблизительно по звучанию от последней ударной гласной, поэтому неточные и авторские созвучия могут остаться нераспознанными. Результат используется для продолжений без изменения сохранённых ручных настроек и ударений.
- Строки как отдельные блоки Tiptap; Enter начинает строку, пустая строка отделяет строфы. Вставка многострочного текста сохраняет строфы.
- Ровно десять продолжений после 1,5 секунды без набора. Каждый новый символ заново отсчитывает паузу; перемещение курсора не запускает генерацию. Кнопка «Рифмы» и Cmd/Ctrl + Space отправляют запрос сразу. При изменении текста старый запрос отменяется, устаревшие ответы не вставляются.
- Рифмовка ABAB, AABB, ABBA, AAAA или свободная. Схема начинается заново после пустой строки. Можно вручную выбрать опорную строку, в том числе из другой строфы.
- Точная, неточная или свободная рифма. Ямб, хорей, дактиль, амфибрахий, анапест и свободный стих; от одной до восьми стоп.
- Библиотека, поиск, избранное, копирование, скачивание `.txt`, режим фокуса и мобильный интерфейс.
- Автосохранение в браузере. Аккаунта и синхронизации между устройствами пока нет. При очистке данных браузера стихи удалятся; сохраняйте важные тексты через скачивание.

## Клавиатура

| Действие | Клавиши |
| --- | --- |
| Новая строка | Enter / Shift+Enter |
| Запросить подсказки | Cmd/Ctrl + Space |
| Выбрать подсказку | Alt + ↑ / ↓ |
| Вставить выбранную | Tab |
| Скрыть подсказки | Escape |
| Поставить / снять ударение | Cmd/Ctrl + Shift + U |
| Поиск | Cmd/Ctrl + K |
| Новое стихотворение | Cmd/Ctrl + N |
| Отмена / повтор | Стандартные сочетания редактора |

Подсказка дописывается от курсора; текст после курсора и другие строки сохраняются. Само начало строки не переписывается. Вставленное продолжение можно отменить одним действием.

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

Для предпросмотра сборки сервер запускается отдельно: `npm run dev:server`. `npm start` запускает только сервер API. `npm run dev` предназначен для локальной разработки, публикация приложения в этом проекте не настроена.

Размер и рифма задаются модели продолжений как ограничения. Ударения анализируются отдельно, по словарю и контексту, без подгонки под выбранный размер; затем локальная проверка сравнивает их с ритмической схемой. Допускаются пропуски ударений в сильных долях и обычные окончания от последнего сильного слога до двух безударных после него. Автоматический анализ может требовать ручного уточнения омографов и авторского произношения; подсветка служит ориентиром, а не литературным запретом.

Текущий стих отправляется в локальный ChatMock, который обращается к модели через свою авторизованную сессию. Ключи и токены в браузер не передаются, остальные стихи библиотека никуда не отправляет. Подробности API, ограничений и явно обозначенного режима без нейросети — в [server/README.md](server/README.md).

Локальные словарные данные и лицензия MIT: [RUAccent snapshot](server/data/ruaccent/README.md). Они используются только сервером и не входят в браузерную сборку.
